# Proto→JSON Conversion

## Setup

```properties
INPUT_SCHEMA_DATA_TYPE=protobuf
SCHEMA_REGISTRY_ENABLED=true
SCHEMA_REGISTRY_URL=http://stencil:8080/descriptors/events.OrderEvent/latest
SCHEMA_REGISTRY_PROTO_CLASS=events.OrderEvent
SCHEMA_REGISTRY_REFRESH_STRATEGY=long_polling
SCINK_HTTP_DATA_FORMAT=json
```

## Flow

```
1. Startup: fetch FileDescriptorSet from registry URL
2. Parse descriptor → find proto class → build DynamicMessage parser
3. Per message: proto.Unmarshal → DynamicMessage → protojson.Marshal → JSON
4. Send JSON to HTTP sink with Content-Type: application/json
5. Background goroutine: long-polls for updates → atomic parser swap
```

## Schema Refresh

| Strategy | Behavior |
|----------|----------|
| `long_polling` | Holds connection up to 5min, swaps parser on new descriptor |
| `periodic` | Fetches every `REFRESH_INTERVAL_MS` (default 5min) |
| `none` | Fetches once on startup, no refresh |
