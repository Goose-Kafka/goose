# Multi-Instance Deployment

Each Goose deployment is fully independent — different topic, consumer group, sink URL, schema, filter, and validation.

## Example: Payment System

```bash
# Order processing
helm install goose-orders ./helm \
  --set env.SOURCE_KAFKA_TOPIC=orders \
  --set env.SOURCE_KAFKA_CONSUMER_GROUP_ID=goose-order-processor \
  --set env.SINK_HTTP_SERVICE_URL=http://order-service:8080/process

# Payment notifications
helm install goose-payments ./helm \
  --set env.SOURCE_KAFKA_TOPIC=payments \
  --set env.SOURCE_KAFKA_CONSUMER_GROUP_ID=goose-payment-notifier \
  --set env.SINK_HTTP_SERVICE_URL=http://notification-service:9090/send

# Analytics with filtering
helm install goose-analytics ./helm \
  --set env.SOURCE_KAFKA_TOPIC=user-events \
  --set env.SOURCE_KAFKA_CONSUMER_GROUP_ID=goose-analytics \
  --set env.SINK_HTTP_SERVICE_URL=http://analytics:3000/ingest \
  --set env.SINK_HTTP_FILTER_ENABLED=true \
  --set env.SINK_HTTP_FILTER_JSONPATH='message.event_type in ["signup","purchase"]'

# Audit to MongoDB
helm install goose-audit ./helm \
  --set env.SINK_TYPE=mongodb \
  --set env.SOURCE_KAFKA_TOPIC=audit-logs \
  --set env.SOURCE_KAFKA_CONSUMER_GROUP_ID=goose-audit \
  --set env.SINK_MONGO_CONNECTION_URL=mongodb://mongo:27017 \
  --set env.SINK_MONGO_DATABASE=audit \
  --set env.SINK_MONGO_COLLECTION=logs
```
